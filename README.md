# pgextwin extension catalog website

[日本語](README_ja.md) | English

The [pgextwin website](https://pgextwin.github.io/website/en/) helps you find **unofficial Windows x64 binaries** for PostgreSQL extensions.

## Find a package

1. Search by extension name or description, or filter by PostgreSQL major version.
2. Check the extension's availability, runtime requirements, and upstream documentation.
3. Download the ZIP for your PostgreSQL major version. Open the linked GitHub Release for its release notes and other files.
4. Check the ZIP against its listed SHA-256 checksum before installing. Read the extension's installation instructions; some require preload configuration and a restart.

A published binary can remain downloadable after the PostgreSQL major reaches end of community support. Availability does not mean the PostgreSQL version is still maintained.

## Other Windows extension sources

The site also lists possible alternatives and future candidates. These are **not** pgextwin binaries unless the catalog explicitly identifies a published pgextwin package. Check each external provider's license, compatibility and support policy.
