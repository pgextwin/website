pgextwin

PostgreSQL拡張機能のWindowsバイナリ

使用しているPostgreSQLのバージョンに合う、Windows x64向け拡張機能の非公式バイナリを探せます。公開済みZIPのダウンロード、導入要件、SHA-256の確認まで、このページで案内します。

バイナリを探す CLI v0.3.5 他のWindows配布元 pgextwinについて

はじめて利用する方へ

ダウンロードまでの3ステップ

  1. 拡張機能を探す。名前で検索し、使用中のPostgreSQLメジャーバージョンで絞り込みます。
  2. 対応状況を確認する。拡張機能を開き、導入要件と対象バージョンを確認してZIPをダウンロードします。
  3. ファイルを照合して導入する。ZIPのSHA-256を確認し、各拡張機能の導入手順に従ってください。ZIPの取得だけではインストールされません。

Windows CLI · v0.3.5

複数の拡張機能をCLIでまとめてダウンロード

公開Catalogに登録された拡張機能のZIPを、指定したPostgreSQLバージョンごとに一括取得できます。CLIはCatalogの署名を確認し、ZIPのSHA-256を照合します。過去の固定版は--fixedで選べます。個別ZIPの署名検証は行わず、判定はINTEGRITY_ONLYです。

.\pgextwin.exe download-all --pg all

Windows拡張機能の対応状況

pgextwinで配布中の拡張機能、今後の実装候補、他のWindowsバイナリ配布元を確認できます。「pgextwinで実装予定なし」は「Windowsで使用できない」という意味ではありません。

外部配布物は記載されたプロジェクトまたはベンダーが提供します。pgextwinはその正確性、安全性、更新状況、サポート、互換性を保証しません。導入前に提供元の利用条件と対象PostgreSQLバージョンの要件をご確認ください。

PostgreSQLのサポート期間

ダウンロードできても、サポート期間内とは限りません

配布中は、そのPostgreSQLバージョン用のバイナリが公開されていることを示します。一方、サポート期間内はPostgreSQLコミュニティのサポート状況です。サポートが終了したバージョンのZIPも、過去の配布物として残る場合があります。

整合性と検証情報

ダウンロードしたZIPのSHA-256を確認してください

各ZIPには、公開済みのSHA256SUMS.txtと照合できるSHA-256を表示しています。署名・ビルド来歴などの情報がある場合も、それだけで安全性や互換性が保証されるわけではありません。脆弱性レポートは作成時点の検査結果です。

このプロジェクトについて

pgextwinが公開するパッケージについて

pgextwinはPostgreSQL拡張機能の非公式Windows x64パッケージを公開する独立したコミュニティプロジェクトです。各パッケージの上流プロジェクト、ソースのバージョン、対応PostgreSQLバージョン、ライセンスを確認できます。
