pgextwin

PostgreSQL拡張機能のWindowsバイナリ

お使いのPostgreSQLのバージョンに対応するWindows x64向け拡張機能の非公式バイナリを探せます。公開済みZIPのダウンロード先、導入要件、SHA-256の確認方法を案内します。

バイナリを探す CLI v0.3.15 他のWindows配布元 pgextwinについて

はじめて利用する方へ

探す → 選ぶ → ダウンロード → 照合

  1. 探す — 拡張機能名で検索し、PostgreSQLのバージョンで絞り込みます。
  2. 選ぶ — 対応するバージョンと導入要件を確認します。
  3. ダウンロード — 対象のZIPを取得します。複数のZIPをまとめて取得する場合はWindows CLIが便利です。
  4. SHA-256で照合 — ダウンロードしたZIPのハッシュ値を確認してから、拡張機能ごとの導入手順に従います。

Windows CLI · v0.3.15 · 正式版

外部バイナリ11件もまとめてダウンロード

Windows CLIなら、oracle_fdw 2.9.0・pgvector 0.8.7（それぞれPG14〜18）とpg_trickle 0.108.3（PG18）の計11 ZIPを提供元から一括取得できます。pgextwinが公開するZIPも一括取得できます。

外部配布の11 ZIPを取得
.\pgextwin.exe download-all --source external
pgextwinの公開ZIPを取得
.\pgextwin.exe download-all --pg all

PostgreSQLのバージョンや拡張機能を指定して絞り込むこともできます。CLIはダウンロード専用で、インストールは行いません。

Windows拡張機能の対応状況

pgextwinで配布中の拡張機能、今後の実装候補、外部のWindowsバイナリ配布元を確認できます。「pgextwinで実装予定なし」はWindowsで使用できないことを意味しません。

外部配布物は、記載されたプロジェクトまたはベンダーが提供します。pgextwinは、その正確性、安全性、更新状況、サポート、互換性を保証しません。導入前に、提供元の利用条件と対象PostgreSQLバージョンの要件をご確認ください。

PostgreSQLのサポート期間

ダウンロードできてもサポート期間内とは限りません

「配布中」は、そのPostgreSQLバージョン用のバイナリが公開されていることを示します。一方、「サポート期間内」はPostgreSQLコミュニティのサポート状況を示します。サポートが終了したバージョンのZIPも、過去の配布物として残る場合があります。

ダウンロード後の確認

ZIPのSHA-256を確認する

ダウンロードしたZIPについて、PowerShellで次のコマンドを実行します。表示された値が拡張機能の詳細にあるSHA-256と一致することを確認してください。

Get-FileHash .\downloaded-file.zip -Algorithm SHA256

このプロジェクトについて

pgextwinが公開するパッケージについて

pgextwinは、PostgreSQL拡張機能の非公式Windows x64パッケージを公開する独立したコミュニティプロジェクトです。各パッケージの上流プロジェクト、ソースのバージョン、対応PostgreSQLバージョン、ライセンスを確認できます。

ご利用前の注意

pgextwinの配布物は非公式です。対応するPostgreSQLのバージョン、提供元のライセンス、必要な設定を確認してください。ZIPをダウンロードするだけではインストールされません。外部配布物については、各提供元の案内もご確認ください。
