pgextwin CLI

Windows CLI v0.3.17

PostgreSQL拡張機能のZIPをWindowsでまとめてダウンロードできます。

pgextwinの配布ZIPと、外部の提供元から直接取得するZIPでコマンドが異なります。--pgでお使いのPostgreSQLのメジャーバージョンを指定してください。

CLIを入手 コマンド例 SHA-256を確認 拡張機能一覧

Windows x64 · 正式版 · 2026年11月18日公開

CLIを入手

pgextwin.exe をダウンロード（13.68 MB） GitHubでリリース情報を見る SHA256SUMS.txt を表示

EXEサイズ：13,683,305 バイト

EXEのSHA-256：bfac89a324029339603caab6c0ec39139419a005f523969500bdd861711c7a83

ダウンロード後、PowerShellで次のコマンドを実行してください。表示されたSHA-256が上記の値またはSHA256SUMS.txtの値と一致することを確認します。

Get-FileHash .\pgextwin.exe -Algorithm SHA256

コマンド例

コマンド例

対象の外部ZIPをまとめて取得

.\pgextwin.exe download-all --source external

外部配布からPostgreSQL 18用を取得

.\pgextwin.exe download-all --source external --pg 18

pgvector 0.8.7のPostgreSQL 18用ZIPを取得

.\pgextwin.exe download-all --source external --extension pgvector --version 0.8.7 --pg 18

pgextwin公開ZIPをまとめて取得

.\pgextwin.exe download-all --pg all

過去の固定版を選ぶ

.\pgextwin.exe download-all --pg all --fixed

進行状況を表示

.\pgextwin.exe download-all --source external --verbose

現在の対象外部ZIP（23件）

  • oracle_fdw 2.9.0：PostgreSQL 14～18（5 ZIP）
  • pgvector 0.8.7：PostgreSQL 14～18（5 ZIP）
  • pglogical 2.4.8：PostgreSQL 15～18（4 ZIP）
  • pg_crash 0.3：PostgreSQL 15～18（4 ZIP）
  • PostGIS／pgRoutingバンドル：PostgreSQL 15～18（4 ZIP）
  • pg_trickle 0.108.3：PostgreSQL 18（1 ZIP）

CLIはカタログの外部取得レコードから最新の対象一覧を読み込みます。期限付きの許可は不要で、取得したZIPはハッシュとサイズで照合します。

使い方は3ステップ

使い方は3ステップ

  1. 1. pgextwin.exeを取得

    上のボタンからEXEをダウンロードし、使用するフォルダーに保存します。

  2. 2. コマンドを実行

    そのフォルダーでPowerShellを開き、上のコマンド例から選びます。--pgでPostgreSQLのバージョンを指定します。外部ZIPの場合は--extensionと--versionで拡張機能とバージョンを選べます。

  3. 3. ZIPを照合

    取得したZIPのSHA-256を確認し、提供元の導入手順に従ってください。

ZIPの照合例

実際のファイル名に置き換えて実行し、提供元やダウンロード結果のSHA-256と照合してください。

Get-FileHash .\downloaded-file.zip -Algorithm SHA256

ご利用前の注意

外部配布物は、それぞれの提供元が公開しています。対応するPostgreSQLバージョンとライセンスを確認してください。PostgreSQL 14の公式サポートは2026年11月12日に終了しました。CLIはダウンロード専用で、拡張機能のインストールや設定変更は行いません。

リリースノート

CLI v0.3.17

v0.3.17（2026年11月18日）は、外部ZIPの取得を期限付きの認可から切り離し、カタログの取得レコード（ハッシュ・サイズ固定）に基づいて常時取得できるようにしました。拡張機能が追加されるたびに最新のカタログに追従します。過去の固定版を取得するには--fixed、進行状況を表示するには--verboseを指定します。公開EXEは13,683,305バイト（13.68 MB）です。
