pgextwin CLI

Windows CLI v0.3.15

外部配布の11 ZIPとpgextwinの公開ZIPをWindowsでまとめてダウンロード。

PostgreSQLのバージョン、拡張機能名、拡張機能の版を指定して取得できます。ダウンロードしたファイルは自動インストールされません。

CLIを入手 コマンド例 SHA-256を確認 拡張機能一覧

Windows x64 · 正式版 · 2026年11月12日公開

CLIを入手

pgextwin.exe をダウンロード（12.90 MB） GitHub Release v0.3.15 SHA256SUMS.txt を表示

EXEサイズ：12,904,699 バイト

EXEのSHA-256：2f573a33765c1c0103ac898674b11e849a643f174844c8caeddf15afd64ebb9f

ダウンロード後、PowerShellで次のコマンドを実行してください。表示されたSHA-256が上記の値またはSHA256SUMS.txtの値と一致することを確認します。

Get-FileHash .\pgextwin.exe -Algorithm SHA256

コマンド例

コマンド例

外部配布の11 ZIPをすべて取得

.\pgextwin.exe download-all --source external

外部配布のPG18用だけ取得

.\pgextwin.exe download-all --source external --pg 18

pgvector 0.8.7 のPG18用ZIPを指定して取得

.\pgextwin.exe download-all --source external --extension pgvector --version 0.8.7 --pg 18

pgextwin公開ZIPをまとめて取得

.\pgextwin.exe download-all --pg all

過去の固定版を選ぶ

.\pgextwin.exe download-all --pg all --fixed

進行状況を表示

.\pgextwin.exe download-all --source external --verbose

対象の外部ZIP（合計11件）

  • oracle_fdw 2.9.0：PostgreSQL 14～18（5 ZIP）
  • pgvector 0.8.7：PostgreSQL 14～18（5 ZIP）
  • pg_trickle 0.108.3：PostgreSQL 18（1 ZIP）

使い方は3ステップ

使い方は3ステップ

  1. 1. pgextwin.exeを取得

    上のボタンからEXEをダウンロードし、使用するフォルダーに保存します。

  2. 2. コマンドを実行

    そのフォルダーでPowerShellを開き、目的のコマンドを実行します。--pg、--extension、--versionで対象を絞り込めます。

  3. 3. ZIPを照合

    取得したZIPのSHA-256を確認し、提供元の導入手順に従ってください。

ZIPの照合例

実際のファイル名に置き換えて実行し、提供元やダウンロード結果のSHA-256と照合してください。

Get-FileHash .\downloaded-file.zip -Algorithm SHA256

ご利用前の注意

外部配布物は、それぞれの提供元が公開しています。対応するPostgreSQLバージョンとライセンスを確認してください。PostgreSQL 14の公式サポートは2026年11月12日に終了しました。CLIはダウンロード専用で、拡張機能のインストールや設定変更は行いません。
