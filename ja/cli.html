pgextwin CLI

Windows CLI v0.2.2

Windows x64用の読み取り専用pgextwin.exeです。ローカルのCatalog情報から14拡張を検索できます。拡張機能のインストーラーや拡張バイナリの真正署名検証器ではありません。

ダウンロードと検証

CLI v0.2.2 GitHub Release

Releaseからpgextwin.exeとSHA256SUMS.txtを入手し、ファイルのSHA256とGitHubの署名付きビルド来歴を照合してください。

Get-FileHash .\pgextwin.exe -Algorithm SHA256
gh attestation verify .\pgextwin.exe --repo pgextwin/catalog --signer-workflow pgextwin/catalog/.github/workflows/cli-candidate.yml --source-ref refs/heads/main --source-digest 594df3d703d983d5978b640a03c64d498765035a

SHA256 (pgextwin.exe): 3567e34cf9f7347cfab7a1292f58965b7bd15e2d8a2bb5b1f0479685633862a0

1行で全70 ZIPをダウンロード

.\pgextwin.exe download-all --pg all

PG14〜18の14拡張、合計70個の公開済み元ZIPを、実行フォルダーに新しいpgextwin-pg14-18フォルダーを作って保存します。PG18だけなら --pg 18 と指定します。

CLI内に固定した過去のP1候補ポリシーのSHA256を使用し、GitHub上の変更されないコミットからポリシーとCatalogの原本を取得・照合します。別途ファイルやSHA256を入力する必要はありません。ZIP本体は固定されたGitHub Release公開URLから取得しSHA256で照合するため、匿名REST APIの回数制限を回避します。数値IDはポリシー固定値であり、その都度RESTで検証するわけではありません。これは固定された2026年10月時点のカタログで、最新版の自動追従ではありません。

途中失敗時は一時ファイルを破棄し、既存ファイルは上書きしません。個別ZIPはINTEGRITY_ONLYで、正式な全70行のP1署名受入、統合署名ZIPの作成、インストールや拡張ZIPの真正署名検証を意味しません。

使い方

index.jsonとextensions/を含むCatalogリポジトリのローカル展開先を指定して実行します。Catalogの一覧情報は明示的にUNVERIFIEDです。

.\pgextwin.exe --version
.\pgextwin.exe list --catalog-dir C:\path\to\catalog --pg 18
.\pgextwin.exe search cron --catalog-dir C:\path\to\catalog --format json

機能範囲と安全性

一覧・検索・JSON出力に対応します。一括ダウンロード用の過去の候補ポリシー固定値はCLIに内蔵されていますが、成功してもINTEGRITY_ONLYです。拡張の真正Sigstore検証、インストール、サービス自動変更、オフライン一括ZIP作成は未提供です。CLI本体はSigstore来歴に対応しますが、Windows Authenticode署名は付いていません。
