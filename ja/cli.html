pgextwin CLI

Windows CLI v0.6.0

PostgreSQL拡張機能のZIPに加えて、空間拡張・ツール・ドライバもWindowsでダウンロードできます。PostgreSQLが入っていない環境でも、ダウンロードだけなら使えます。

listやsearchで対象を探し、downloadで名前を指定して取得できます。まとめて取得する場合はdownload-allを使います。--pgでお使いのPostgreSQLのメジャーバージョンを指定してください。

CLIを入手 コマンドの使い方 SHA-256を確認 拡張機能一覧

Windows x64 · プレリリース · 2026年11月21日公開

CLIを入手

pgextwin.exe をダウンロード（13.69 MB） GitHubでリリース情報を見る SHA256SUMS.txt を表示

EXEサイズ：13,696,554 バイト

EXEのSHA-256：0845a9838910ce362f39c07d005a09011c5237c4285d97d9b3afe036ce6dc371

ダウンロード後、PowerShellで次のコマンドを実行してください。表示されたSHA-256が上記の値またはSHA256SUMS.txtの値と一致することを確認します。

Get-FileHash .\pgextwin.exe -Algorithm SHA256

コマンドの使い方

< >で囲んだ箇所は実際の値に置き換えてください。[ ]で囲んだオプションは省略できます。

一覧表示と検索

.\pgextwin.exe list [--category <category>] [--pg <major|all>] [--format <text|json>]
.\pgextwin.exe search <term> [--category <category>] [--pg <major|all>] [--format <text|json>]

カテゴリはextensions（拡張機能）、spatial（空間拡張）、tools（ツール）、drivers（ドライバー）です。

名前を指定して取得

.\pgextwin.exe download <item> [--version <version>] [--pg <major|all>] [--category <category>] [--output <dir>]
.\pgextwin.exe download <item> --source pgextwin --pg <major> [--version <version>] [--output <dir>]

既定では外部の提供元から取得します。--versionでカタログに記録されたバージョンを指定できます（外部パッケージと、--source pgextwinで取得するpgextwin配布の拡張機能の両方）。

まとめて取得

.\pgextwin.exe download-all --pg <major|all> [--output <dir>] [--latest|--fixed]
.\pgextwin.exe download-all --source external [--pg <major|all>] [--category <category>] [--output <dir>]

既定ではpgextwinの最新の配布一覧を使います。過去の固定版を使うには--fixedを指定します。外部の配布物を取得するときに--pgを省略すると、カタログに記録されたすべてのPostgreSQLメジャーバージョンが対象になります。--outputで既存のフォルダーを指定できます。省略時は作業中のフォルダーに保存します。詳細な実行ログを表示するには--verboseを付けます。

ヘルプとCLIのバージョンを表示

.\pgextwin.exe --help
.\pgextwin.exe --version

コマンド例

PostgreSQL 18用のpgvectorを取得

.\pgextwin.exe download pgvector --pg 18

PostgreSQL 18用のpgvector 0.8.7を取得

.\pgextwin.exe download pgvector --version 0.8.7 --pg 18

PostgreSQL 15用のHypoPG 1.4.4を取得

.\pgextwin.exe download hypopg --source pgextwin --pg 15 --version 1.4.4

PostgreSQL 18用の外部拡張機能を一覧表示

.\pgextwin.exe list --category extensions --pg 18

PostgreSQL 18用のベクトル関連パッケージを検索

.\pgextwin.exe search vector --pg 18

PostgreSQL 18用の外部拡張機能ZIPをまとめて取得

.\pgextwin.exe download-all --source external --pg 18 --category extensions

PostgreSQL 18用のpgextwin配布ZIPをまとめて取得

.\pgextwin.exe download-all --pg 18

psqlODBCドライバーを取得

.\pgextwin.exe download psqlodbc

PostgreSQL 19用のPostGISを取得

.\pgextwin.exe download postgis --pg 19

PostgreSQL 19用のpgRoutingを取得

.\pgextwin.exe download pgrouting --pg 19

  • pgvector 0.8.7：PostgreSQL 14～18
  • pglogical 2.4.8：PostgreSQL 15～18
  • pg_crash 0.3：PostgreSQL 15～18

  • ドライバ：psqlODBC 13.02

CLIはカタログの取得レコードから最新の対象一覧を読み込みます。期限付きの許可は不要で、取得したファイルはハッシュとサイズで照合します。PostgreSQLがインストールされていない環境でも、ダウンロードのみに使えます。

使い方は3ステップ

使い方は3ステップ

  1. 1. pgextwin.exeを取得

    上のボタンからEXEをダウンロードし、使用するフォルダーに保存します。

  2. 2. コマンドを実行

    そのフォルダーでPowerShellを開きます。downloadに取得したい名前を指定します。外部配布物のバージョンを指定する場合は--versionを付けます。まとめて取得する場合はdownload-allを使います。--pgでPostgreSQLのメジャーバージョンを指定します。

  3. 3. ZIPを照合

    取得したZIPのSHA-256を確認し、提供元の導入手順に従ってください。

ZIPの照合例

実際のファイル名に置き換えて実行し、提供元やダウンロード結果のSHA-256と照合してください。

Get-FileHash .\downloaded-file.zip -Algorithm SHA256

ローカルファイルの検証

verify externalは、取得済みの外部ZIPをレビュー記録と照合し、SHA-256、ファイルサイズ、ZIPの構造を確認します。

.\pgextwin.exe verify external --ledger <file> --input-dir <dir> --pg <major|all>

verify reportは、別途確認したハッシュ値と手元のファイルを使って、拡張機能1件の署名付きレポートを認証します。

.\pgextwin.exe verify report <item> --pg <major> --catalog-dir <dir> --policy <file> --policy-sha256 <hex> --trusted-root-sha256 <hex> --p1-verifier-sha256 <hex> --report <file> --signature <file> --authority-key <pem> --authority-key-sha256 <hex>

ご利用前の注意

外部配布物は、それぞれの提供元が公開しています。対応するPostgreSQLバージョンとライセンスを確認してください。PostgreSQL 14の公式サポートは2026年11月12日に終了しました。CLIはダウンロード専用で、拡張機能のインストールや設定変更は行いません。

リリースノート

CLI v0.6.0

v0.6.0（2026年11月22日）は、署名付きカタログからpgextwin配布の拡張機能をバージョン指定で取得できます。たとえばPostgreSQL 15用のHypoPGは、最新版1.4.5に加えてdownload hypopg --source pgextwin --pg 15 --version 1.4.4で1.4.4も取得できます。PostgreSQL 19向けのOSGeoバンドル（PostGIS 3.7.0、pgRouting 4.0.1）を含む外部カタログにも対応し、外部拡張・空間バンドルはPostgreSQL 15〜19で取得できます。公開EXEは13,696,554バイト（13.69 MB）です。
