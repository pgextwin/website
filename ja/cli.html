pgextwin.exeをダウンロード（12.83 MB） GitHub Release v0.3.5 SHA256SUMS.txt

公開SHA256SUMS.txtと一致することを確認し、CLI本体のビルド来歴も検証してください。

標準動作はCatalog承認・登録済みの最新Releaseです。GitHub REST APIの認証情報は不要。元ZIPは実行フォルダー内の新しいフォルダーに保存されます。

最新版Catalog · 登録されたすべてのZIP
.\pgextwin.exe download-all --pg all
最新版Catalog · PG18向けの全登録ZIP

最新版Catalogの拡張に対応

--verbose で進行状況を表示

署名付きCatalogの検証、ZIPごとの取得開始、8 MiBごとの転送量、SHA256再照合、一括保存の完了をUTC時刻付きで表示します。詳細ログは標準エラー出力に分離され、通常の標準出力とJSONは変更しません。

すべてのZIPの取得を詳細表示
.\pgextwin.exe download-all --pg all --verbose
詳細ログをファイルに保存
.\pgextwin.exe download-all --pg all --verbose 2> download-verbose.log

ログの有効化は拡張ZIPの署名検証やインストール権限を追加しません。元ZIPの判定は引き続きINTEGRITY_ONLYです。

How it works / 動作のしくみ

動作のしくみ

最新版・固定版の2経路が、共通のZIPバイト整合性検証と安全な保存処理に合流します。インストール処理は含みません。

1 · 取得元を選択
LATEST

最新版（標準）

公開CatalogフィードとSigstore署名をHTTPSで取得。発行元、署名、コミット、固定Catalog原本を確認します。

FIXED

固定版（--fixed）

CLI内にSHA256で固定された過去の不変Catalog・ポリシースナップショットを使用します。

  1. 2 · ZIPを選択

    Catalog登録済みのReleaseタグから、指定したPostgreSQLバージョン用の元ZIPを選択。上流の最新タグを独断で採用しません。

  2. 3 · 取得・照合

    GitHub Releaseの元ZIPを制限付きHTTPS経由で取得し、各ファイルのSHA256を検証。危険なリダイレクトや一部失敗を拒否します。

  3. 4 · 保存・証跡

    全件成功後に新しいフォルダーとして確定し、DOWNLOAD-INFO.jsonを出力。既存の成果物は上書きしません。

    DOWNLOAD-INFO.json

検証できること・できないこと

SIGSTORE VERIFIED

CLI本体

GitHub ActionsのSigstore来歴を検証。公開EXEのSHA256も独立照合済みです。

SIGSTORE VERIFIED

Catalogフィード（最新版）

Sigstore署名と不変Catalog原本のSHA256を独立検証します。

INTEGRITY_ONLY

拡張機能の元ZIP

認証済み・固定済み情報とのSHA256整合性のみ（INTEGRITY_ONLY）。個別ZIPの真正署名・来歴やインストール認可は成立していません。

このCLIはダウンロード専用です。ZIPのインストール、サービス変更、統合署名ZIP作成、個別拡張の公開認可は実行しません。

CLI v0.3.5 — 17拡張と署名済みPostgreSQL対応範囲に追従。 v0.3.5以降に保護mainへ取り込まれた変更を搭載しました。認証済みの最新CatalogはpgTAP、pg_variables、pg_store_plansを含む17拡張を登録し、CLI側に新規拡張名を固定列挙しません。PostgreSQLの対象メジャーはPG14〜18固定ではなく、署名検証済みCatalogが承認した連続範囲から選択します。将来のPGメジャーは、署名付きCatalogと実ZIPの正式登録・SHA256検証が成立するまで利用可能とは扱いません。過去の固定版--fixedと--verboseの標準エラー進捗表示は継続します。

Windows x64 EXEは12,833,222バイト。署名付き最新版Catalogと従来の--fixedを継続サポート。異常なZIPは拒否し、不完全な一括出力や既存成果物の上書きは行いません。

信頼境界： CLIとCatalogフィードの来歴・署名検証に対し、拡張機能の元ZIPはINTEGRITY_ONLY（バイト整合性のみ）です。個別ZIPの真正署名検証、インストールや拡張機能の正式公開認可を追加したわけではありません。
