Windows用EXEを入手

pgextwin.exeをダウンロード（12.89 MB） GitHub Release v0.3.8 SHA256SUMS.txt

公開EXEのSHA256: aecb0537622148b46b731b543ce511ee281877f4e6fbc31c77f8346689ce6077

ダウンロード後、最初のPowerShellコマンドでSHA-256を確認できます。2つ目のコマンドはCLI本体のビルド来歴の検証に使用します。

Get-FileHash .\pgextwin.exe -Algorithm SHA256
gh attestation verify .\pgextwin.exe --repo pgextwin/catalog --signer-workflow pgextwin/catalog/.github/workflows/cli-candidate.yml --source-ref refs/heads/main --source-digest 3ce07983ef0a93069b2b0ba850b9dc970e3f373f

目的に合うコマンドを選ぶ

標準では、公開Catalogに登録された最新版を取得します。GitHub APIの認証情報は不要です。取得したZIPは実行フォルダー内の新しいフォルダーに保存し、既存ファイルは上書きしません。

最新版Catalog · 登録されたすべてのZIP
.\pgextwin.exe download-all --pg all
最新版Catalog · PG18向けの全登録ZIP
.\pgextwin.exe download-all --pg 18
過去の固定版 · PG14～18の70 ZIP
.\pgextwin.exe download-all --pg all --fixed
別途取得した外部ZIP原本をオフライン一括検証（自動取得なし）
.\pgextwin.exe verify-external-all --ledger .\evidence\issue112-external-pg18-direct-link-review-v1.json --input-dir C:\original-external --pg 18
pg_trickle PG18 の外部原本を取得（有効な署名許可が必要）
.\pgextwin.exe download-all --source external --pg 18 --output C:\pgextwin-external --external-admission .\external\external-get-admission.json --external-bundle .\external\attestation.json

verify-external-all は、別途入手したZIPをオフラインで照合するコマンドです。確認用台帳は取得許可ではありません。外部原本の直接取得には、対象原本ごとに有効な本人承認済みのGET専用許可が必要です。同一発行Runの署名付き許可JSONとSigstore証明を保存し、既存の出力先フォルダーを指定してください。期限切れ・署名不一致・対象外では取得を拒否します。許可のない外部原本は DOWNLOAD_DENY、ミラー・再配布は MIRROR_DENY です。

最新版Catalogの拡張に対応

進行状況を確認・保存する

署名付きCatalogの検証から、ZIPごとの取得開始、8 MiBごとの転送量、SHA256再照合、一括保存の完了までをUTC時刻付きで表示します。詳細ログは標準エラー出力に記録し、通常の標準出力とJSONは変更しません。

すべてのZIPの取得を詳細表示
.\pgextwin.exe download-all --pg all --verbose
詳細ログをファイルに保存
.\pgextwin.exe download-all --pg all --verbose 2> download-verbose.log

ログの有効化は拡張ZIPの署名検証やインストール権限を追加しません。元ZIPの判定は引き続きINTEGRITY_ONLYです。

How it works / 動作のしくみ

動作のしくみ

最新版と固定版の2つの取得経路は、共通のZIPバイト整合性検証と保存処理を使用します。インストール処理は含みません。

1 · 取得元を選択
LATEST

最新版（標準）

公開CatalogフィードとSigstore署名をHTTPSで取得。発行元、署名、コミット、固定Catalog原本を確認します。

FIXED

固定版（--fixed）

CLI内にSHA256で固定された過去の不変Catalog・ポリシースナップショットを使用します。

  1. 2 · ZIPを選択

    Catalogに登録されたReleaseタグをもとに、指定したPostgreSQLバージョン向けの原本ZIPを選びます。上流の最新タグを自動的に採用することはありません。

  2. 3 · 取得・照合

    GitHub Releaseの原本ZIPを制限付きHTTPS経由で取得し、各ファイルのSHA256を検証します。危険なリダイレクトや一部の取得失敗は拒否します。

  3. 4 · 保存・証跡

    全件成功した場合に新しいフォルダーへの保存を確定し、DOWNLOAD-INFO.jsonを出力します。既存の成果物は上書きしません。

    DOWNLOAD-INFO.json

検証できること・できないこと

SIGSTORE VERIFIED

CLI本体

GitHub ActionsのSigstore来歴を検証。公開EXEのSHA256も独立照合済みです。

SIGSTORE VERIFIED

Catalogフィード（最新版）

Sigstore署名と不変Catalog原本のSHA256を独立検証します。

INTEGRITY_ONLY

拡張機能の元ZIP

認証済みの固定情報とのSHA256整合性のみを確認します（INTEGRITY_ONLY）。個別ZIPの真正署名・来歴の検証やインストール認可は成立していません。

このCLIはダウンロード専用です。ZIPのインストール、サービス変更、統合署名ZIP作成、個別拡張の公開認可は実行しません。

リリースノート

日本語

CLI v0.3.8では、pg_trickle PG18と過去版HypoPG 1.4.1 PG14〜16の原本直接取得に対応しました。 本人承認と独立Sigstore検証を経た有効期限内の許可がある場合に限り、提供元から利用者の端末へ原本ZIPを取得してサイズとSHA256を照合します。期限切れや対象外の場合は DOWNLOAD_DENY です。verify-external-all によるオフライン照合も利用できます。

公開Windows x64 EXEは12,892,708バイト。保護mainの来歴 3ce07983ef0a93069b2b0ba850b9dc970e3f373f と公開EXEのSHA256 aecb0537622148b46b731b543ce511ee281877f4e6fbc31c77f8346689ce6077 を検証済みです。公開EXEによる通常のWindows一括取得では17拡張・85 ZIPを照合しました。

信頼境界：外部提供元ZIPの検証状態は INTEGRITY_ONLY です。外部ZIPのミラー・再配布・インストールは行いません。oracle_fdwとコミュニティ版pgvectorの取得許可は保留中です。
