pgextwin CLI

Windows CLI v0.2

Windows x64用の読み取り専用pgextwin.exeです。ローカルのCatalog情報から14拡張を検索できます。拡張機能のインストーラーや拡張バイナリの真正署名検証器ではありません。

ダウンロードと検証

CLI v0.2.0 GitHub Release

Releaseからpgextwin.exeとSHA256SUMS.txtを入手し、ファイルのSHA256とGitHubの署名付きビルド来歴を照合してください。

Get-FileHash .\pgextwin.exe -Algorithm SHA256
gh attestation verify .\pgextwin.exe --repo pgextwin/catalog --signer-workflow pgextwin/catalog/.github/workflows/cli-candidate.yml --source-ref refs/heads/main --source-digest 529718ac8ff829c8a98b57d26adb1d74971588c1

SHA256 (pgextwin.exe): 1764d2f5a54b9fa715a2bba1d068493ef1d5dcb159b895e3f24becf2dee6fdc0

ZIP一括ダウンロード

PG14〜18の1バージョンにつき14件、全5バージョンで70件のオリジナルZIPを一括取得できます。独立して認証されたP1ポリシーとSHA256を必要とします。

.\pgextwin.exe download-all --pg 18 --catalog-dir C:\approved\catalog --policy C:\approved\policy.json --policy-sha256 APPROVED_SHA256 --output C:\pgextwin-downloads
# --pg all は70件

一括取得は元の個別ZIPを保存し、途中で失敗すれば一時フォルダーを破棄します。結果はINTEGRITY_ONLYで、統合署名ZIPの生成・インストール・拡張ZIPの真正署名検証ではありません。

使い方

index.jsonとextensions/を含むCatalogリポジトリのローカル展開先を指定して実行します。Catalogの一覧情報は明示的にUNVERIFIEDです。

.\pgextwin.exe --version
.\pgextwin.exe list --catalog-dir C:\path\to\catalog --pg 18
.\pgextwin.exe search cron --catalog-dir C:\path\to\catalog --format json

機能範囲と安全性

一覧・検索・JSON出力に対応します。拡張ZIPの取得は独立したPolicyの固定値が必要で、成功してもINTEGRITY_ONLYです。拡張の真正Sigstore検証、インストール、サービス自動変更、オフライン一括ZIP作成は未提供です。CLI本体はSigstore来歴に対応しますが、Windows Authenticode署名は付いていません。
