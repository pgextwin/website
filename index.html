pgextwin

PostgreSQL Extensions for Windows

Unofficial Windows x64 binaries for selected PostgreSQL extensions, designed for standard Windows PostgreSQL installations.

標準的なWindows版PostgreSQLで利用しやすい、PostgreSQL拡張機能の非公式Windows x64バイナリを提供します。
