# pgextwin 拡張機能カタログ

[English](README.md) | 日本語

[pgextwinの日本語サイト](https://pgextwin.github.io/website/ja/)では、PostgreSQL拡張機能の**非公式Windows x64バイナリ**を探せます。

## ダウンロードまでの手順

1. 拡張機能名や説明で検索するか、PostgreSQLのメジャーバージョンで絞り込みます。
2. 公開状況、利用条件、上流ドキュメントを確認します。
3. 利用中のPostgreSQLメジャーバージョンに一致するZIPをダウンロードします。変更内容や付属ファイルの詳細は、リンク先のGitHub Releaseで確認できます。
4. ZIPのSHA-256を表示された値と照合してから、各拡張機能のインストール手順に従ってください。追加設定や再起動が必要な拡張機能もあります。

PostgreSQLのサポート終了後も、過去のバイナリをダウンロードできる場合があります。ダウンロードできても、PostgreSQLのサポートが継続しているとは限りません。

## pgextwin以外の入手先

サイトには、ほかのWindows向け配布元や将来の候補も掲載しています。これらは**pgextwinが公開するバイナリと区別**して表示しています。外部の配布物を利用する際は、各提供元のライセンス、互換性、サポート条件を確認してください。
