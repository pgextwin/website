pgextwin CLI

Windows CLI v0.2

Read-only pgextwin.exe for Windows x64. Discover 14 extension packages from a local Catalog snapshot. This preview is not an installer or a verified extension-package signature engine.

Download and verify

CLI v0.2.0 on GitHub Releases

Download pgextwin.exe and SHA256SUMS.txt from the release; verify the SHA256 locally and the cryptographically signed GitHub build provenance.

Get-FileHash .\pgextwin.exe -Algorithm SHA256
gh attestation verify .\pgextwin.exe --repo pgextwin/catalog --signer-workflow pgextwin/catalog/.github/workflows/cli-candidate.yml --source-ref refs/heads/main --source-digest 529718ac8ff829c8a98b57d26adb1d74971588c1

SHA256 (pgextwin.exe): 1764d2f5a54b9fa715a2bba1d068493ef1d5dcb159b895e3f24becf2dee6fdc0

Bulk original ZIP downloads

Download all 14 original ZIP assets for one PostgreSQL major, or 70 across PG14–18. An independently authenticated P1 policy and SHA256 are required.

.\pgextwin.exe download-all --pg 18 --catalog-dir C:\approved\catalog --policy C:\approved\policy.json --policy-sha256 APPROVED_SHA256 --output C:\pgextwin-downloads
# --pg all selects 70 ZIP assets

Original ZIPs are kept separate; incomplete batches are rolled back. The result is INTEGRITY_ONLY, not a signed combined offline ZIP, an installer, or verified extension provenance.

Usage

Run the CLI with a locally extracted Catalog repository snapshot (including index.json and extensions/). Catalog results explicitly remain UNVERIFIED.

.\pgextwin.exe --version
.\pgextwin.exe list --catalog-dir C:\path\to\catalog --pg 18
.\pgextwin.exe search cron --catalog-dir C:\path\to\catalog --format json

Scope and safety

list/search and JSON output are supported. Original extension downloads require independent policy pins and provide only INTEGRITY_ONLY. Genuine extension Sigstore verify, installation, automatic service changes and offline bundle generation are not provided. The CLI binary has Sigstore build provenance, not a Windows Authenticode signature.
