Download commands

Download commands

Download all 11 external ZIPs

.\pgextwin.exe download-all --source external

Download external ZIPs for PG18 only

.\pgextwin.exe download-all --source external --pg 18

Choose pgvector 0.8.7 for PG18

.\pgextwin.exe download-all --source external --extension pgvector --version 0.8.7 --pg 18

Download pgextwin-published ZIPs

.\pgextwin.exe download-all --pg all

Use an older fixed selection

.\pgextwin.exe download-all --pg all --fixed

Show download progress

.\pgextwin.exe download-all --source external --verbose

Three steps to download

Three steps to download

  1. 1. Download pgextwin.exe

    Use the download button above and save the EXE in your preferred folder.

  2. 2. Run a command

    Open PowerShell in that folder and choose a command. Narrow by --pg, --extension, or --version as needed.

  3. 3. Verify your ZIP

    Check the ZIP's SHA-256, then follow the provider's installation instructions.

ZIP verification example

Replace the example file name with the downloaded ZIP and compare the SHA-256 with the download information or provider's published checksum.

Get-FileHash .\downloaded-file.zip -Algorithm SHA256

Before you use the downloads

Third-party ZIPs come from their respective providers. Check PostgreSQL compatibility and licenses. Official PostgreSQL 14 support ended on November 12, 2026. The CLI is download-only; it does not install extensions or change settings.
