Commands

Replace placeholders in <angle brackets> with your values. Options in [square brackets] are optional.

Browse and search

.\pgextwin.exe list [--category <category>] [--pg <major|all>] [--format <text|json>]
.\pgextwin.exe search <term> [--category <category>] [--pg <major|all>] [--format <text|json>]

Categories are extensions, spatial, tools, and drivers.

Download one named item

.\pgextwin.exe download <item> [--version <version>] [--pg <major|all>] [--category <category>] [--output <dir>]
.\pgextwin.exe download <item> --source pgextwin --pg <major> [--output <dir>]

Named downloads use external providers by default. Add --version to select an exact version recorded in the Catalog.

Download packages in bulk

.\pgextwin.exe download-all --pg <major|all> [--output <dir>] [--latest|--fixed]
.\pgextwin.exe download-all --source external [--pg <major|all>] [--category <category>] [--output <dir>]

Bulk downloads use the current pgextwin feed by default. Use --fixed for the historical pgextwin snapshot. External downloads include all recorded PostgreSQL majors when you omit --pg. Use --output to choose an existing directory, or save to the current directory by default. Add --verbose for detailed diagnostics.

Show help or the CLI version

.\pgextwin.exe --help
.\pgextwin.exe --version

Three steps to download

Three steps to download

  1. 1. Download pgextwin.exe

    Use the download button above and save the EXE in your preferred folder.

  2. 2. Run a command

    Open PowerShell in that folder. Use download with the item name and add --version if you need a specific external release. Use download-all for a bulk selection. Set --pg to your PostgreSQL major version.

  3. 3. Verify your ZIP

    Check the ZIP's SHA-256, then follow the provider's installation instructions.

ZIP verification example

Replace the example file name with the downloaded ZIP and compare the SHA-256 with the download information or provider's published checksum.

Get-FileHash .\downloaded-file.zip -Algorithm SHA256

Advanced local verification

verify external checks local provider ZIPs against a review ledger, including SHA-256, size, and ZIP structure.

.\pgextwin.exe verify external --ledger <file> --input-dir <dir> --pg <major|all>

verify report authenticates a signed report for one extension using independently pinned local inputs.

.\pgextwin.exe verify report <item> --pg <major> --catalog-dir <dir> --policy <file> --policy-sha256 <hex> --trusted-root-sha256 <hex> --p1-verifier-sha256 <hex> --report <file> --signature <file> --authority-key <pem> --authority-key-sha256 <hex>

Before you use the downloads

Third-party ZIPs come from their respective providers. Check PostgreSQL compatibility and licenses. Official PostgreSQL 14 support ended on November 12, 2026. The CLI is download-only; it does not install extensions or change settings.
