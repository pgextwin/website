Getting started

Find → Choose → Download → Verify

  1. Find — Search by extension name and filter by your PostgreSQL major version.
  2. Choose — Check the matching version and installation requirements.
  3. Download — Get the ZIP file, or use the Windows CLI for multiple packages.
  4. Verify — Compare the downloaded ZIP's SHA-256, then follow that extension's installation steps.

Windows CLI · v0.3.15 · Stable

Get all 11 external Windows ZIPs in one command

The Windows CLI can download oracle_fdw 2.9.0 and pgvector 0.8.7 (PG14–18 each), plus pg_trickle 0.108.3 (PG18) directly from their providers. It also supports batch downloads of pgextwin-published ZIPs.

All 11 external ZIPs
.\pgextwin.exe download-all --source external
pgextwin ZIPs
.\pgextwin.exe download-all --pg all

Choose an extension or PostgreSQL version to narrow your download. The CLI downloads files but does not install them.

PostgreSQL lifecycle

Downloadable does not always mean supported

Available means a binary has been published for that PostgreSQL version. Maintained refers to the PostgreSQL community support period. ZIPs for unsupported PostgreSQL versions may remain downloadable as historical releases.

After downloading

Check the ZIP's SHA-256

Run the following in PowerShell with your downloaded ZIP file name. Compare the result with the SHA-256 shown in the extension details.

Get-FileHash .\downloaded-file.zip -Algorithm SHA256

About

About pgextwin packages

pgextwin is an independent community project publishing unofficial Windows x64 packages for PostgreSQL extensions. Each package identifies the upstream project, source version, supported PostgreSQL versions, architecture, and license.

GitHub Published catalog Windows CLI

Before you install

pgextwin packages are unofficial. Check PostgreSQL compatibility, provider licenses, and required configuration. Downloading a ZIP does not install it. For third-party packages, consult the original provider's documentation.
